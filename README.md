# 🌟 صفحة تسجيل دخول تفاعلية بإضاءة نيون (Neon Login Page)

صفحة تسجيل دخول (Login Page) واجهة مستخدم حديثة وأنيقة، مجهزة بالكامل باللغة العربية ومتوافقة مع الشاشات (Responsive). تتميز الصفحة بتأثيرات إضاءة النيون الـ (Neon Glow Effects) التفاعلية عند تحريك الماوس (Hover).

---

## ✨ المميزات (Features)

* **تصميم عصري وجذاب:** يعتمد على الخلفية الداكنة وتأثيرات النيون الأزرق (`#0ef`).
* **تأثيرات تفاعلية (Hover Effects):** يتغير شكل الإطار، الأزرار، الأيقونات، والنصوص بالكامل بسلاسة عند مرور الماوس فوق الكارت.
* **دعم كامل للغة العربية:** واجهة مكتوبة باللغة العربية مع اتجاه نص من اليمين لليسان (`dir="rtl"`).
* **أيقونات ذكية:** استخدام مكتبة `Font Awesome` لإضافة أيقونات مميزة للبريد الإلكتروني وكلمة المرور.
* **متجاوب (Responsive):** التصميم يتوسط الشاشة بشكل ممتاز على جميع الأجهزة.

---

## 🛠️ التكنولوجيات المستخدمة (Technologies Used)

* **HTML5:** لبناء هيكل الصفحة الأساسي.
* **CSS3:** للتنسيق، ضبط الألوان، وعمل حركات الإضاءة والـ Transitions.
* **Font Awesome (v6.4.0):** لعرض أيقونات حقول الإدخال.
